# multiphase_axion

Code supporting the article

> L. B. Ho, *Multiparameter sensing of axion dark matter with superconducting-qubit networks* (2026).

The repository contains a variational entangled sensor network of $N=5$
transmon qubits that jointly estimates the two Cartesian components
$(x, y) = (\delta\cos\alpha, \delta\sin\alpha)$ of the axion-induced rotation.
The state-preparation circuit is trained to minimize $\mathrm{Tr}(\mathbf{Q}^{-1})$
(quantum Fisher information matrix), the measurement circuit is then trained to
minimize $\mathrm{Tr}(\mathbf{C}^{-1})$ (classical Fisher information matrix),
and the coupling $g_{a\gamma\gamma}$ is reconstructed by sequential Bayesian inference.

Only source code is tracked. Checkpoints (`*.pkl`), result files (`*.json`, `*.npy`)
and figures are regenerated by the scripts into `topo/data/` and `topo/figure/`.

## Layout

```
onecircuit/            variational-circuit library (ansatz, QFIM/CFIM, noise, optimizers)
axion_reach_results/   axion_coupling.py: delta <-> g_agg conversion, KSVZ/DFSZ lines
topo/
  run/                 training and Bayesian-recovery scripts (write to topo/data/)
    R1, R5, R6, R7/    additional analyses added during the revision
  plot/                plotting scripts (read topo/data/, write topo/figure/)
  run_topology.sh, slurm_topology.sbatch, submit_all.sh   batch drivers
  README.md            detailed description of every script and parameter
```

## Installation

```bash
git clone https://github.com/echkon/multiphase_axion.git
cd multiphase_axion
pip install -r requirements.txt
```

The scripts add the repository root to `sys.path`, so installing `onecircuit` is
optional (`pip install -e .` also works). `tqix` imports PyTorch; install the CPU
build of `torch` if it is not already present.

## Workflow

Each script is configured by constants at the top of the file
(`TOPOLOGY = 'star' | 'ring' | 'full'`, `LAYERS`, ...) and is run without arguments.
Scripts can be launched from any directory.

| Step | Script | Output |
|---|---|---|
| Train state preparation, $\min \mathrm{Tr}(\mathbf{Q}^{-1})$ | `topo/run/train_qfi.py` | `ckpt_qfi_*`, `costs_qfi_*` |
| Train measurement, $\min \mathrm{Tr}(\mathbf{C}^{-1})$ | `topo/run/train_cfi.py` | `ckpt_cfi_*`, `costs_cfi_*` |
| Noisy training ($T_1$, $T_2$, CZ error) | `topo/run/train_noise.py` | `*_network_noise_*` |
| Bayesian recovery of $\delta$ | `topo/run/bayes_recover.py` | `bayes_recover_results_*` |
| Recovery of $g_{a\gamma\gamma}$ vs. mass | `topo/run/recover_mass.py`, `recover_mass_noise.py` | `targeted_mass_bayes_results_*` |
| Random DM phase per coherence window | `topo/run/R6/rand_fig3.py`, `rand_fig3_xy.py`, `rand_fig4.py` | `fig3_randomphase*.json`, `fig4_randomphase.json` |
| Uncertainty vs. interrogation time | `topo/run/tau_scan.py` | `tau_scan.npy` |

The exclusion curves in `plot_recover_mass*.py` read `ADMX2018.txt`, `ADMX2021.txt`,
`RBF.txt` and `UF.txt` from `topo/data/`. These public limits are available from
[AxionLimits](https://github.com/cajohare/AxionLimits).

See [`topo/README.md`](topo/README.md) for the full description of each script.
